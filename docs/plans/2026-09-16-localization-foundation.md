# Task 3：中英文本地化基础

承接用户确认图标主屏幕与 App 内显示正常后的“继续”。本轮只实现原计划 Task 3，不推进新模型、桥接协议或 Obsidian 功能。

## 设计

- `AppLanguage` 保存独立 `app.language` 偏好：`system / en / zh-Hans`。没有历史选择时默认英文；不写系统 `AppleLanguages`，不迁移已有业务配置。
- `AppLanguageSettings` 向现有根视图注入 Locale；切换语言不以 `.id` 重建根视图、连接对象或任务状态。
- 在设备页齿轮或工具页偏好设置中进入语言页。支持跟随系统、English、简体中文。系统简体中文使用中文，其他系统语言回退英文。
- 固定界面文字集中于 `Resources/Localizable.xcstrings`；展示层显式查询英文键。插值模板保留参数，日期和常见数字按 Locale 显示。
- 用户输入、语音转写、模型回答、任务审批正文、笔记标题/正文、原始诊断与协议值不经过通用翻译。已有 Picker 存储标签和业务标识不随语言变化。
- DEBUG 界面测试使用独立 UUID 偏好域，语言启动参数只在有效测试域内生效。

## 验证与交付

- 独立 Foundation/Combine 语言选择测试与目录完整性检查：`scripts/run_localization_tests.sh`。
- App 内资源读取测试，模拟器界面验证英文→中文→重启→英文，并检查与界面键同名的用户草稿仍保持原文。
- 在隔离生成的工程中构建。真机构建沿用已有配置的 Bundle ID 和签名；原位安装，不卸载或重新配对。
- 本轮增量基于 `artifacts/localization/baseline`，精确差异与输出保存在 `artifacts/localization/`。不将早先未提交的 Hermes/Codex 改动计入本轮。

最终验证：独立语言测试 8 项和目录检查 3 项通过；模拟器 App 单元与界面测试共 19 项通过，覆盖英文→中文→英文、重启保留、用户草稿不变，以及已知应用状态的显示层本地化。目录现有 1034 个条目。最终真机构建通过，已确认手机上存在同一 Bundle ID 后原位安装并成功启动到设备页；没有卸载或重新配对。

Task 3 的基础设施、主要界面和常见应用状态已完成。已知动态状态按限定格式匹配，只翻译应用拥有的模板；地名、天气描述、协议数值、用户原文、外部回复和原始诊断保持原文。部分深层工具页的动态服务诊断仍可能显示中文，不能据此宣称每条状态都有完整英文翻译；后续随各功能验收补齐。用户提出控制 token 消耗后，未扩大到新模型、桥接协议或 Obsidian 功能。没有修改 PROJECT.md / AGENTS.md；当前项目不是科研计算项目，没有新增运行环境或全局包。
