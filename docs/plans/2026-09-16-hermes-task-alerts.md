# Hermes 任务提醒增量

现有 Hermes 任务卡已经在手机上显示状态、结果和一次性审批；Codex 已有眼镜提醒。本次补齐 Hermes 的眼镜提醒，不改变 Hermes 桥接协议、任务提交或审批入口。

- 提醒默认关闭，由用户在会话页的 Hermes 任务卡中开启。开启时把当前任务状态设为基线，只提示之后的新变化。
- 仅提醒待审批、待回答、电脑本地操作、完成、失败和结果待核对。眼镜通知是通用短句，不包含任务正文、回答、提示详情或审批选项；审批始终在 iPhone 上进行。
- 眼镜忙或未就绪时保留待提醒状态，状态过期则取消旧提醒。发送前先记录尝试；SDK 结果未知时不自动重发。提醒随当前桥接地址隔离，换地址后不会重放旧任务。
- 与现有 Codex 提醒一样，只有 iOS 允许 App 运行且眼镜已连接、通知来源允许时才尝试发送；不承诺锁屏、系统挂起或强制退出后的实时到达。
- Hermes 任务卡提供眼镜通知设置入口；提醒开关不会替用户打开眼镜通知总开关或改写来源过滤配置。

验证：测试先复现了快速任务和“先开启提醒、后配置地址”时的漏报，再通过 7 项针对性测试。Hermes/Codex 提醒、本地化单元与界面组合回归共 33 项通过；最后的地址边界修复后重新运行 7 项提醒测试。最终真机构建通过，并在确认同一 Bundle ID 已存在后原位安装、成功启动。实际镜片显示仍需用户开启开关后观察一次新任务通知。
