> **刷完还有最后一步：释放升级保护！** 眼镜正常重启不代表手机已完成收尾。GUARD-07 必须按第4节完成「只读回查 → 解除结果保护」，否则安卓 App 仍可能拦住官方语音、录音、字幕、待办等功能。**不要因此重刷、解绑或清空 App 数据。**

## 先拿对文件

下载同一个 [Android GUARD-07 / TAP1-TEST-01 Release](https://github.com/Turbo1123/Turbo-IO/releases/tag/android-105-guard07-tap1-test01) 中的：

1. `TurboIO-RayNeo-1.0.5-GUARD07-PUBLIC.apk`：已合并插件的完整 **非官方修改版**，不是原厂原样 APK。
2. `TurboIO-TAP1-TEST-01.zip`：眼镜完整 OTA 包。**不要解压、重新压缩、改内部文件或与其他候选混用。**
3. `SHA256SUMS.txt`：下载完整性校验。

手机最低 Android 10、arm64；实测组合为 Samsung Fold3 / Android 15、RayNeo AI **1.0.5（201）**、雷鸟 iO、Strix OS **1.0.4.12**。其他眼镜型号、宿主版本或原厂固件版本没有验证；不匹配就停止，不修改门禁硬上。

该固件由最近使用的 TAP1 实验运行时派生，可见标记为眼镜菜单的 **「显示TEST」**。APK 一次只接受这一份固定大小与 SHA-256 的固件，其他包会被拒绝。

## 1. 安装 APK、连接眼镜

- 从 Release 下载 APK，在 Android 系统中允许当前下载/文件管理器安装应用，然后安装。
- APK 保留官方包名 `com.rayneo.venus.pub`，但不是官方签名。**不能覆盖签名不同的官方版本。** 若系统提示签名冲突，先通过原 App 导出需要保留的本地录音、稿件和配置，再自行决定卸载旧 App；卸载会删除沙盒数据，不能保证恢复。不要先卸载再找备份。
- 这是研究分发签名，不是作者的个人开发者身份。签名私钥不公开。系统安全警告不代表应当无条件忽略，请核对下载来源与摘要。
- 正常登录、授予附近设备/蓝牙等官方所需权限、连接眼镜。插件沿用官方连接；不要为刷机反复解绑、重置或连接两个宿主。
- 打开右上角 **Turbo IO → 实验固件升级 · 默认锁定**，确认说明出现 **GUARD-07 · 预检有效期2分钟**。
- 公共包不附带作者的模型、搜索、地图、字幕服务 Key、Cookie、账号或私人服务器。服务配置需要用户自己填写；**刷机本身不需要这些第三方服务 Key。**

## 2. 仅下载、校验，不立即刷

开始前让眼镜回首页，结束录音、语音、提词、导航、音乐和阅读。眼镜电量至少 **50%**，手机保持充足电量、前台亮屏和稳定蓝牙连接。

1. 插件升级页点 **「1 · 开启 15 分钟官方只下载」**，选择下载的 `TurboIO-TAP1-TEST-01.zip`。
2. 点「返回官方 App」，关掉插件页面，进入 **眼镜 → 设置 → 关于本机 → Strix OS / 眼镜软件版本**。
3. 检查更新，确认更新说明包含 **TAP1-TEST-01**。版本数字仍可能是 **1.0.4.12**，不要以“数字没变”认定下载失败。
4. 点官方「软件更新」完成手机下载、校验和解压；若已有同一份有效缓存，官方可能直接显示 **「新软件版本已准备就绪」**。
5. 看到「开始安装」时，**先不要点**，还需要单次授权。

此时本机来源仅开放15分钟，不是公网固件服务器；未授权的升级发送会被拦截。

## 3. 预检 → 授权 → 官方开始安装

1. 回到 Turbo IO 的升级页，点 **「2 · 只读预检（不授权、不刷写）」**。
2. 等待 **官方目录15/15校验通过**，并确认版本、电量、空闲均为 `true`。空间可能暂为 `false`，由官方在最终开始前查询；不允许跳过。
3. 点 **「3 · 校验目录并允许一次试刷」**，阅读风险说明，输入 **`TAP1-TEST-01`**，确认。
4. 等到 **授权：1 / 阶段：ARMED**，返回官方准备就绪弹窗，点 **「开始安装」一次**。

单次授权最长15分钟；开始预检证据有效期为2分钟，授权等待期间自动刷新只读状态。退后台会撤销尚未使用的授权；断连、忙碌或校验失败仍然禁止开始。这不是“两分钟内完成刷机”的限制。

**之后不要重复点击、强退 App、切换宿主、关闭蓝牙、断电或主动重启眼镜。** 保持手机前台，等官方传输与眼镜安装完成。上传百分比只代表传输进度，不代表眼镜安装成功。

## 4. 必做：自然重启 → 只读回查 → 释放保护

1. 等眼镜自然回首页，确认菜单里有 **「显示TEST」**。
2. 检查菜单、仪表盘、连接，以及自己常用的功能。版本号仍相同不等于失败，也不能代替标记检查。
3. 回到 **Turbo IO → 实验固件升级 · 默认锁定**，向下滚动到页面底部。若显示 `INSTALLING / 结果保护：待核对`，表示手机还在保护状态；**不要再次点击安装**。
4. 只有亲眼确认更新已结束、眼镜自然回首页且镜片菜单正常后，点 **「已自然回首页：允许只读回查」→「确认」**。等待最短保护期及同一眼镜稳定连接条件通过，再等待页面出现新的 **版本=true、空闲=true**。没有回执就不能继续。
5. 确认镜片「显示TEST」标记及菜单正常后，及时点 **「已检查显示TEST：解除结果保护」→「确认」**，只点一次。当前回读结果约60秒内有效，超时请重新做上一步只读回查，不重刷。
6. 确认状态变为 **`阶段：LOCKED`、`授权：0`、`结果保护：未开始`**，并提示人工验收已记录。这里的 `LOCKED` 指“再次刷机默认锁定”，**不是日常功能被锁**；官方业务应恢复放行。最后再测官方语音、录音或字幕等常用功能。

**第4、5步不是可选诊断，是 GUARD-07 的刷机收尾。** 未释放时，手机会继续拦截官方业务；本轮用户遇到“安卓官方功能都不能用、iOS正常”，在完成释放后确认恢复。这是安卓升级保护未收尾，不是应当重新刷固件的信号。

若释放被拒绝，保留状态并检查同一眼镜连接与新回执；不要靠重启、卸载、清数据或删除保护记录绕过。若仍处于更新、黑屏或是否结束不明，**绝不能点这两个确认按钮**。

## 遇到问题，在哪一步停

| 现象 | 处理 |
| --- | --- |
| APK 签名冲突 | 停止；先导出旧 App 数据，不能直接覆盖官方签名 |
| 不出现 TAP1-TEST-01 | 检查是否 GUARD-07、是否选择指定 ZIP、15分钟来源是否过期；未授权前可重新准备，不盲点升级 |
| 校验失败、不是15/15 | 停止；重新下载指定文件并核对 SHA-256，不改文件或白名单 |
| 电量/空闲/版本不通过 | 先结束任务、恢复连接；重新只读预检，不放宽门禁 |
| 开始被拦截且0片 | 留存状态；不是刷写成功，也不要连续点；先查首次错误 |
| 已有传输/更新但卡住、断连或黑屏 | 不重刷、不清数据、不强退/重启；保持供电，记录时间和阶段，联系维护者判断 |
| 已回首页但仍待核对 | 按第4节人工验收和只读回查；不要将保护锁当作需要再刷 |
| 刷完安卓官方语音/录音/字幕等没有反应 | 先检查是否仍“结果保护：待核对”；确认眼镜已自然回首页后按第4节回查并释放，勿重刷 |

高级排查可导出 `Android/data/com.rayneo.venus.pub/files/official-ota-guard-status.txt`；提交前检查账号、设备标识和其他日志是否含隐私。不要上传 Cookie、Key 或完整沙盒。
