## 更新价值

- 从270×110放大变为540×220点对点显示，保留更多小字与边缘细节。
- 四个55行分块，逐块CRC及整图CRC；完整收齐才切帧，坏包/漏块/乱序不呈现半张画面。
- 仍是原有双缓冲239424字节，不增加第三张全屏缓存；单消息最大14999字节。
- 兼容旧TVP1播放、已继承的菜单/遥控/导航等；手机可选完整画面/局部放大/拖动/灰阶。
- AP **7,435,336字节**，比TVP1增加1024字节，低于9,600,000字节门槛；仅修改AP，其余14个新版原厂载荷不变，仍有40个既有补丁点。

此固件**不含 AirPlay 接收核心**；接收、H.264解码与图像处理在iPhone，眼镜只处理有界灰度分块。原厂代码/资源版权不变；这里只能许可本项目有权授权的原创扩展，不能把原厂二进制当作原创源码。

## 重建

使用[同版本原厂1.0.5.5 ZIP](../strix-1.0.5.5/README.md)，其SHA-256必须为 `2927917f976ef3c9b183253e2342a7a0c85a3e454e973876100f3158da5ec367`。

```sh
python3 build.py --stock /path/to/original.zip \
  --llvm-bin /path/to/pinned/llvm/bin --out build/reproduced
```

发布前已用导出源码重建，AP、模块与ZIP字节一致。使用的LLVM来自DevEco工具链仅作为ARM编译器，不意味着固件运行鸿蒙；换工具链若输出哈希不同，脚本拒绝通过。`build-inputs.json`固定全部编译单元、顺序和原厂补丁白名单；编译不会连接手机、下载私密资料或刷写。

```sh
python3 build.py --stock /path/to/original.zip --audit /path/to/TVP2.zip
```

继承11组回归以及TVP1/TVP2 ARM入口、像素、内存哨兵、CRC/乱序/漏块、暂停退出和超时离线测试通过，概要见 [verification.json](verification.json)。这些不是全部实机功能的验收证明。
