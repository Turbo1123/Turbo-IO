# TWR1：手机与 AP 阅读协议

仅针对 Strix OS 1.0.4.12 的 TWR1 实验 AP。固件内不运行微信读书 Skill、不联网、不解码原始封面、不接收整本 EPUB。

## 下行

沿既有官方文件通道，文件名 `turbo-reader.twr`。完整文件必须 `received == declared`，长度32–512B；进UI队列前深复制。每个包是32B头 + 最多480B负载，所有多字节整数为小端：

| 偏移 | 含义 |
| --- | --- |
| 0 | `TWR1` |
| 4 / 5 / 6–7 | 版本1 / 操作码 / 保留0 |
| 8 / 12 | 非零SID / 单调序列号 |
| 16 / 20 | 页修订号 / 块偏移（QUERY为已消费事件号） |
| 24 / 28 | 负载长 / 整包CRC32，计算时此CRC字段置0 |

操作：1 OPEN；2 BEGIN（总长+正文CRC32，各u32）；3 CHUNK（严格连续offset）；4 COMMIT；5 SETTINGS（30–480字/分+自动0/1，各u32）；6 CLOSE；7 QUERY。

当前SID只允许一个事务；序号相同且CRC相同可识别重包，旧序号/冲突包拒绝。COMMIT只在完整长度、总CRC和内容结构通过后进入待呈现；成功回执不意味着屏幕已经画完。

### 书架（kind=1）

64B元数据：kind@0，首本索引@4，总本数@8，本页数@12（0–4）。紧跟每本5824B：书名96B、作者64B、非零token4B@160、保留至192、封面5632B（64×88 L8）。一页四本23360B。

### 阅读（kind=2）

256B元数据：kind@0，首行@4，总行数@8，窗口行数@12，顶行@16，速度@20，自动@24，book token@28，书名96B@64，来源/章节96B@160。随后每行128B，最多64行，正文包最大8448B。

字符串均有界NUL终止、尾部填零、严格UTF-8，不含控制字符。手机按约48显示格换行；字形宽度并非真实测量，特别长的英文词/罕见字符仍需镜片验收。

## 上行

官方业务15、PB版本1/类型6，JSON `cmd=turbo_read_v1`，`payload.data`为48B回执的小写hex。

`WRA1`@0，版本1@4，event@5，result@6，active/automatic位@7；SID@8、seq@12、revision@16、event_id@20、event_value@24、book token@28、row@32、speed@36、kind@40、CRC32@44（覆盖前44B）。

event：0 ACK、1请求书架、2打开book token、3请求正文顶行、4已退出、5保留进度事件。result：0成功、1格式错误、2旧包、3忙、4无会话。

### OPEN-FIX-02 进入状态与错误细分

OPEN 成功表示已接受进入请求，不表示镜片已经完成绘制。遇到渲染忙，每50ms检查一次，最长等待5秒；不绕过渲染/DMA空闲保护。期间预留阅读的输入归属，允许长按取消。首次绘制成功后才结束 opening 状态。超时发送 CLOSED/result=3 并回收常亮租约，缓冲释放仍等待渲染空闲。

仅在非零 result 的 ACK/CLOSED 中，`event_value@24` 用作失败原因：0未细分、1启动器/业务状态不允许、2连接未就绪、3正在退出、4其他扩展占用、5渲染忙、6控件或字体初始化失败、7事件注册失败、8常亮申请失败、9等待渲染超过5秒。成功事件的原有含义不变，协议版本与包长不变。旧版固件的非零回执不能据此反推精确原因。

阅读页专用根控件工厂使用已完成布局的 launcher surface 初始化尺寸，再显式设置各控件的最终尺寸，不读取刚创建父控件尚未更新的坐标来判断尺寸合法性。导航/音乐等模块的通用绘图适配器未修改。

物理菜单进入先发SID=0的书架请求，手机再建立SID；不冒充BLE系统唤醒能力。普通事件按event_id去重，并借QUERY确认消费。手机同时检查蓝牙deviceId和当前SID，避免跨设备或旧回包。

## 内存、退出与流控

- AP两个24 KiB bank，共49,152B，当前页+接收暂存；完整Control约55KiB，另有LVGL对象、字体、队列及系统开销，不能称总RAM仅49KiB。
- 每页发布前确认原厂渲染空闲；将所有可见封面与静态文本引用切到新帧，隐藏封面解绑后，才交换bank并清零旧bank。
- 显示文本单独双缓冲，不直接引用会被擦除的正文行；向前滚出视口即清除该行。回翻请求手机新窗口，不从已清零内存读取。
- 原厂50ms定时器驱动位移；480是字/分钟，不是480FPS。一次tick最多前进一行，缺窗口暂停。
- WEB-03 的旋钮过滤忽略绝对值≤8的微动，方向变化/超过250ms重置累积，累计600原始单位才步进；步进与按下后有300ms保护，重复按下间隔450ms。精确规则见 `src/official-addon/research/weread-v1/reader_input.h`。这是研究参数，不代表所有设备手感已验收。
- 手动操作暂停自动，短按切换自动；设计上阅读长按请求原书架页、书架长按退出。**长按返回仍有用户报告的异常，未修复，不能把模拟通过写成实机已修好。**
- 父对象先销毁、页面失焦、断连、90秒无手机联系均撤销常亮；延后到渲染空闲释放Control，防止DMA引用已释放缓冲。
- 手机仅一个在途512B包，SDK提交、文件终结和AP ACK全部齐全才清理临时文件并继续；最小间隔120ms，心跳8s，超时15s停发。SDK所有权不明确时保留文件而非误删，最多512个任务目录，达到上限需诊断清理，不能绕过。
- 不在录音/导航/音乐活动期间抢占阅读显示。语音、导航和OTA请求先关闭阅读，等待关闭后再重试。

## 未验证/未实现

此前书架同步有用户实机反馈，本精确版本已确认升级完成并回到首页；真实传输延迟、镜片字体裁切/旋钮方向、后台长时续传、断线重连及原厂所有功能仍未全量验收。公开手机模块没有网页全文适配，也尚未接入默认构建。尚无跨会话阅读进度、本机阅读统计回写、眼镜统计页、复杂EPUB图片排版。不同固件地址不可混用本补丁。
