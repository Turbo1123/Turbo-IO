## 发布的是什么

本次上传先前保留的 TGR1-GLOBAL-01 完整 OTA ZIP，保持原文件名及全部字节，不重新压缩、不修改固件。用户此前反馈“刷完了”，随后反馈全局“翻页翻不了”，此问题仍未定位闭环。文件名中的 `CANDIDATE-NOT-APPROVED` 特意保留：它不是通过稳定性验收的升级推荐。

此次仅重新做离线包审计；没有新刷机、没有对手势/表冠/后台进行新的真机验收，也不把公开源码抽取后的构建当成该历史包的逐字节复现。

| 基线 | Strix OS 1.0.4.12，固定 AP ABI |

## 下载与离线核对

把 ZIP 和 SHA256SUMS 放在同一目录：

```sh
shasum -a 256 -c SHA256SUMS
```

具备原厂 1.0.4.12 解压基线的开发者可进一步复核：

```sh
python3 watch-remote/tests/audit_firmware.py \
  /absolute/TGR1.zip /absolute/stock-1.0.4.12
```

脚本核对完整 ZIP 固定哈希、15 个成员、所有 MD5/Size、AP 长度/哈希、非 AP 字节一致性和敏感字段模式；不接触设备。脱敏结果见 [firmware-audit.json](firmware-audit.json)。敏感字段模式检查不等于穷尽所有隐私风险。

## 刷写兼容条件：不能拿旧 APK 直接刷

- 必须使用专门匹配上述 ZIP/AP/清单的 TGR1 手机 OTA 门禁。仓库已发布的 GUARD-07 APK 固定 TAP1-TEST-01，不能当作本包安装器；不要改名、替换缓存、绕过哈希或解除保护强刷。
- `stage-addon.py` 仅生成 Watch 手机源码派生，默认不启用 OTA。当前没有面向普通用户的预签名 TGR1 配套 IPA/APK；单独下载 ZIP 不代表已经具备可刷环境。
- 已自行完成并审核兼容集成的开发者，仍须按“固定候选导入校验 → 只下载验收 → 官方解压目录全部 15 项复核 → 确认电量至少 50%、无任务 → 单次明确授权 → 官方更新页启动”的顺序操作。不能把离线通过视为升级授权。
- 发送与更新期间不重启/关闭 App、不切换连接、不强制释放保护、不让设备断电。异常时保留日志，不能盲目重复发送。
- 等眼镜自然重启，确认正常首页、实体旋钮和原有功能，再按配套版本完成只读回查与保护收尾；更新未结束或状态不明时不能释放。之后先测试 Watch 屏幕单步输入，再测表冠/手势；已分发回执不代表镜片实际翻页成功。
