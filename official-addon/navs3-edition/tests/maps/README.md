# 公开区域地图回归样本

`hongkong.json`、`shenzhen.json` 是 OpenStreetMap API 0.6 的公开区域摘录，源 URL、范围、下载日期、原始摘要和许可记录在各自 `meta` 中；`replay.json` 为合成移动轨迹，不是用户位置记录。

只用于离线回归，默认不复制进 App。实际导航基于用户所选起终点，首次获取周边路网前需同意向图源发送区域范围；没有预置个人行程或服务凭据。
