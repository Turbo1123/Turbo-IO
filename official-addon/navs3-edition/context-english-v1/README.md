# 情境英语 TEL1 · 从真实上下文准备轻量学习

2026-10-19 · 延续 TMIG1 / App 1.0.6（218）公开的研究功能，本目录配套 NAVS3 / TMG2；以下历史验收不扩写为本轮重新全量验收。**不是自动获得官方云端完整 24 小时记录，也不保证后台永久运行。**

## 手机与眼镜各做什么

- 手机：读取官方 App **已缓存在本机**的智记逐句文字；可选择日期、学习目标、数量，预览片段并确认模型目的地，生成/校验候选，再以 TEL1 有界分片协议发送到眼镜。
- 眼镜：540×180 原生邀请、回忆、答案页面；每日默认 5 个（含复习，最多 10），点头记得/摇头不记得，8 秒无动作跳过；按键作为保守回退，长按退出。佩戴/头控不满足时不伪造手势成功。
- 复习：本机有界结果记录及眼镜持久化进度；当天重发不直接清零当日额度，题库有日期与内容校验。模型可能给错答案、错误翻译或考试难度，使用者需审阅。
- 自动备题：默认关闭；用户看过上传范围并允许后，按设置计划检查已缓存片段、生成与等待空闲发送。队列、去重、失败/未知回执和账户/设备隔离不等于无限后台权限。

## 怎么开始

1. 先装匹配的 NAVS3 手机插件和 TMG2 眼镜固件；进入 TurboIO → 资料/其他功能 → 学习研究 → 情境英语。
2. 在官方全天智记已有记录里加载原文到本机。只有列表/摘要而无逐句缓存时，本模块不能凭空生成正文；无需重新录音，也不要求每次手动“保存最终文字”。
3. 先用离线样例测试题库发送/回执和眼镜入口，不读取私人记录、不调用云模型。
4. 配置自己的模型，选择实际缓存片段，检查目标、数量、目的地与授权说明后生成；审阅题目，再发送并等待眼镜确认。
5. 手动、按键、点头摇头分别验收；最后再开启自动备题/定时提醒。别把“能力已确认”或“已提交”当成画面/手势成功。

## 隐私与可用性边界

只有明确授权后才向选定模型提交选中的片段，不上传整库或记录 API Key/正文请求日志。不要推断片段中的说话人或地点；本机缓存字段不一定代表真实讲话时间，不能把系统接收时间冒充现场时间。

官方本机缓存格式有版本依赖；当前适配宿主 1.0.6（218），新版本需要重新核查。手机被系统挂起、锁定保护数据不可用、断连、升级保护、其他应用占前台或原厂头控资源冲突时，任务可能等待或停止；不保证每天自动推送成功。

用户已确认本轮 TMIG1 新底座能够刷入、进入并兼容匹配 App；**不把这条总体反馈扩写为全部学习交互和自动调度长期验收通过**。源代码的离线测试、手机编译和真实使用反馈应分别看待。
