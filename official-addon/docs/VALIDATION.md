# V2 验证范围 · 2026-09-12

每项区分源码测试、私用前身的真机反馈和公开版尚未验收事项。不以模拟器或发送成功回执代替镜片验收。

| 层级 | 状态 |
| --- | --- |
| Foundation 核心测试 | 19组：个人资料、语音流、工具、待办、导出、提词器、目录/布局等；合成数据 |
| Node 测试 | 13项：Mach-O嵌入边界6项、签名参数/权限2项、知识库5项；不调用私人模型 |
| iOS扩展与UIKit模拟器 | 公开副本能够独立编译；个人资料、模型、知识库页面在无密钥模拟器检查 |
| 个人资料 UI | 称呼、身份和偏好可编辑；本机持久化与提示词组合有测试；不预置维护者身份 |
| 公开版通用打包工具 | 参数/权限合成测试；基于私用打包路径改写，未把公共版生成的新包再次安装所有设备 |
| 私用前身实际反馈 | 官方登录/配对、自有模型文字回答、自然语言待办创建、新闻提词器滚动、导出和底栏等存在实机反馈；具体能力仍依赖版本/会话准备 |
| 新增资料页非越狱真机 | 未单独验收；不能把旧安装包验收移植为此次发布版成功 |
| 知识库 | 只读参考服务与手机工具实现；HTTPS真实手机查询、镜片最终显示和断网恢复未完成 |
| Agent适配 | Codex执行器代码；其他四种仅可持久化选择，未实现调用 |
| APNs | V2未接入；个人签名不自动继承官方推送 |
| 新闻 | 本次进程模板准备后有长稿实测；重启免准备、所有速度档稳定性未验全 |
| 全天智记 | 显式开始保存后的片段导出研究；完整历史、无损保证和长时后台未验全 |

开发者应按顺序验收：无Key编译/预览 → 自有签名安装 → 官方登录/眼镜连接 → 单轮模型 → 流式长回答/退出/插话 → 录音副本分享 → 提词器 → 可选知识库。升级应用/固件后重新验证。

内置模型随机字符串模式只用于链路对照，不能代替自有服务实际调用。所有测试禁止上传真实密钥、签名、设备标识或聊天/音频到公开报告。
