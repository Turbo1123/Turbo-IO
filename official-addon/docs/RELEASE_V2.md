# Turbo IO V2 · 官方 App 扩展源码研究版

面向雷鸟 iO / RayNeo iO 开发者，**源码公开、非商业使用**，沿用 PolyForm Noncommercial 1.0.0。不是面向小白的成品 App；未经授权禁止商用，许可细节见仓库 LICENSE。

## 本次发布

- V1 独立 SDK 保留不变；新增 `official-addon/` 官方 App 扩展路线。
- 自有文字模型、Tools 搜索与待办、AI 新闻提词器、录音/文字和全天智记导出研究入口。
- 模型与对话页新增 Agent 选择、知识库来源；仅 Codex 有执行器实现，其余未接通。
- **个人资料与提示词在程序界面编辑**：称呼、身份、回答偏好；默认留空，不带维护者身份或配置。
- 提供无密钥 UIKit 预览、源码构建、版本校验、本地嵌入与个人签名工具，以及可选 Codex 只读知识库参考服务。
- 19 组 Foundation 测试、13 项 Node 测试通过；iOS 动态库/模拟器构建通过，实际模拟器资料保存和读取通过。

## 不提供

不提供官方 IPA、砸壳文件、修改版 IPA、预签名应用、维护者的 Key、证书、设备信息或私人数据。Release 不附带编译产物；GitHub自动提供的源码归档仍是源码仓库快照，包含V1原有明确列出的第三方构建依赖，不是应用安装包。

实际使用者需自行准备有权使用的兼容应用副本和签名。当前适配官方 iOS 1.0.2 / build 67，非任意 IPA 通用合并工具；加密包拒绝处理，不提供解密或绕过官方权限的程序。

## 仍需研究

知识库手机 HTTPS 到镜片完整闭环、APNs、其他 Agent、新闻重启免校准、全天智记完整历史/无损保证、所有设备和固件兼容均不能声称完成。公开版新资料页尚未单独进行非越狱真机验收，私用前身的成功不代替这次发布验收。
